# 나의 작은 마당 (데모)

물 위에 뜬 작은 섬을 꾸미고 산책하는 3D 웹 데모입니다. 설치 없이 브라우저에서 바로 열립니다.

## 화면 배치
- 맨 위: 섬 제목(수정 가능), 방문자 수·파티 열기·섬 이동 자리(준비 중)
- 3D 화면 바로 위 도구줄: 왼쪽은 사진 · 동영상(준비 중) · 저장 · 소리 · 전체화면, 오른쪽은 시간·날씨
- 3D 화면 안 왼쪽: 인사 · 점프 · 도움말
- 오른쪽 세로 메뉴: 내 공간 · 친구(준비 중) · 아이템(가구 / 옷장·상점 준비 중) · 관리 → 누르면 옆으로 넓은 창이 펼쳐짐
- 3D 화면 아래: 채팅 입력줄(자리만), 맨 아래: 흐르는 소식줄

## 조작법
- 걷기: 땅 클릭, 또는 W A S D / 방향키 · 점프: Space · 인사: 1
- 달리기: 이동 키를 빠르게 두 번 누르고 그대로 누르기, 또는 땅을 더블클릭
- 카메라 돌리기: 마우스를 누른 채 끌기 (Q, E 키도 가능) · 가까이/멀리: 마우스 휠
- 꾸미기: 아이템 → 가구 (또는 I 키) → 물건 고르기 → 땅 클릭. 어디든 자유롭게 놓이고, Shift를 누른 채 놓으면 격자 칸에 맞춰짐
- 돌리기: R은 15도씩, Shift+R은 45도씩
- 격자 보기는 가구 창의 "격자 보기" 버튼으로 켜고 끔

## 파일 구조
- `index.html`, `style.css`: 화면과 버튼
- `js/palette.js`: 모든 색감 (분위기를 바꿀 때 여기만 고치면 됨)
- `js/catalog.js`: 물건 목록과 모양
- `js/world.js`: 섬과 물건 데이터. 모든 변경은 `apply(action)`을 거쳐서, 나중에 여러 명이 함께 놀 때 이 action을 서버로 주고받으면 됩니다.
- `js/avatar.js`: 아바타
- `js/environment.js`: 하늘·시간·날씨·조명
- `js/storage.js`: 저장/불러오기 (지금은 브라우저 저장, 나중에 서버 저장으로 교체)
- `js/sound.js`: 발소리와 빗소리. 소리 파일 없이 코드로 직접 만든 소리라 저작권 문제가 없습니다.
- `vendor/`: 3D 그리기 도구 three.js (MIT 라이선스)

## 채팅 (지금은 혼자 써보기)
- Enter로 입력, 보내면 머리 위 말풍선 + 왼쪽 아래 기록 창. '기록' 버튼으로 기록 창 보이기/숨기기, '꾸미기'로 잘 어울리는 말풍선 조합 4가지(크림·벚꽃·풀잎·노을) 중 하나 고르기.
- `js/chat.js`의 `LocalTransport`만 서버 연결로 바꾸면 친구에게도 보이게 됩니다.
- 화면 글꼴: Pretendard (길형진, SIL Open Font License 1.1) — `vendor/pretendard`에 함께 담아 어느 컴퓨터에서나 같은 글꼴로 보여요.
- 글씨체 출처 (모두 SIL Open Font License 1.1, 무료·상업적 사용 가능, Google Fonts): 고운돋움(Gowun Dodum, 류양희), 주아(Jua, 배달의민족 우아한형제들), 나눔손글씨 펜(Nanum Pen Script, 네이버).

## 친구와 같은 섬에서 (v0.26, 멀티 첫 버전)
- 오른쪽 메뉴 **친구** → 내 이름 적기 → **초대 링크 복사하기** → 친구에게 보내기. 친구는 링크를 눌러 이름만 적고 들어와요(로그인 없음).
- 서로 걷기·달리기·점프·인사, 채팅 말풍선, 발밑 이름표가 보여요. 위쪽 "지금 N명"이 실제 인원으로 바뀌어요.
- 섬 꾸밈·이름·시간·날씨는 주인 것을 그대로 보여 주고, 손님은 못 바꿔요. 손님 화면은 저장하지 않아요(내 섬이 덮어써지지 않게).
- 주인이 게임을 켜 둔 동안에만 들어올 수 있어요. 섬 모습을 주인 화면이 손님에게 직접 보내 주기 때문이에요(서버 저장은 3단계 로그인 때).
- 서버: Supabase Realtime의 broadcast만 사용 (`js/config.js`에 주소와 공개용 열쇠, `js/net.js` 연결 통로, `js/party.js` 함께 놀기). 데이터베이스는 아직 안 씀.
- 개발 시험: 주소 끝에 `?localtest=1`을 붙이면 서버 없이 같은 브라우저 창끼리 연결돼요.
- `vendor/supabase.js`: supabase-js 2.119.0 (MIT 라이선스)

## 주인 / 손님 규칙
섬의 시간·날씨·꾸미기는 주인(방장)이 정하고, 손님은 바꿀 수 없습니다. `js/main.js`의 `setRole('guest')`를 부르면 손님 화면이 됩니다(방문 기능 단계에서 연결).

## 버전
고칠 때마다 `index.html`과 `js/*.js`의 `?v=` 숫자를 함께 올립니다. 브라우저가 예전 파일을 기억해 두지 않고 새 파일을 받게 하기 위해서입니다. 화면 오른쪽 아래에 지금 버전이 보입니다.

## 되돌리기
- `Ctrl`+`Z` 되돌리기, `Ctrl`+`Shift`+`Z`(또는 `Ctrl`+`Y`) 다시 하기. 맥은 `Cmd`.
- 놓기·옮기기·돌리기·치우기·처음 모습으로, 모두 되돌릴 수 있어요 (창을 새로 고치기 전까지, 최근 100번).

## 아이콘
- 아이콘은 이모지 대신 `js/icons.js`에 직접 그린 선 아이콘 한 벌을 써요 (24칸, 선 굵기 1.8, 둥근 끝). 색은 글자 색을 따라가요.
- 아이템 카드 그림은 `js/thumbs.js`가 게임 속 3D 물건을 그대로 찍어서 만들어요. 물건 모양을 고치면 카드도 같이 바뀌어요.
