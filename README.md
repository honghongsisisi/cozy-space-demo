# 나의 작은 마당 (데모)

물 위에 뜬 작은 섬을 꾸미고 산책하는 3D 웹 데모입니다. 설치 없이 브라우저에서 바로 열립니다.

## 화면 배치
- 맨 위: 섬 제목(수정 가능), 방문자 수·파티 열기·섬 이동 자리(준비 중)
- 3D 화면 바로 위 도구줄: 왼쪽은 사진 · 동영상(준비 중) · 저장 · 소리 · 전체화면, 오른쪽은 시간·날씨
- 오른쪽 세로 메뉴: 내 공간 · 친구(준비 중) · 아이템(가구 / 옷장·상점 준비 중) · 관리 → 누르면 옆으로 넓은 창이 펼쳐짐
- 3D 화면 아래: 채팅 입력줄(자리만), 맨 아래: 흐르는 소식줄

## 로그인 · 유령 손님 (v0.41)
- 켜면 로그인 창이 떠요 (뒤에는 광장이 보여요). **이메일 + 비밀번호**로 가입·로그인하고, 게임 안에서는 **별명**으로 보여요. 한 번 로그인하면 브라우저가 기억해서 다음엔 바로 내 섬으로 가요.
- 내 섬(마당·집 안·물건 개수·시간·날씨)은 **서버(Supabase의 `islands` 표)**에 저장돼요. 다른 컴퓨터·휴대폰에서 같은 이메일로 로그인하면 그대로 나와요. 이 컴퓨터에도 임시로 저장해 두고, 켤 때 서버와 비교해 더 새것을 열어요.
- 로그인 없던 때 이 컴퓨터에 꾸며 둔 섬은, 이 컴퓨터에서 **처음 로그인한 계정**으로 한 번만 옮겨 줘요.
- **손님으로 구경하기**: 가입 없이 **유령 모습**으로 광장에서 시작해요. 걷기·점프·인사만 되고, 말하기·꾸미기·저장은 안 돼요. 위쪽 **가입하고 내 섬 받기** 버튼으로 언제든 가입할 수 있어요. 초대 링크로 왔다면 그 섬에 유령으로 들어가요.
- 섬 번호(초대 링크)는 계정에서 만들어져서 어느 기기에서나 같아요. 예전(v0.40까지) 초대 링크는 더 이상 맞지 않아요.
- 서버 표 만들기: `docs/supabase-islands.sql`을 Supabase의 SQL Editor에서 한 번 실행. 표가 아직 없으면 게임은 '이 컴퓨터에만 저장'으로 계속 돌아가요.
- 파일: `js/auth.js` (가입·로그인·서버 저장), `js/storage.js` (이 컴퓨터 임시 보관·예전 저장 옮기기)
- 개발 시험: 주소 끝 `?localtest=1`이면 서버 없이 이 브라우저 안의 가짜 계정으로 시험해요.

## 친구 맺기 · 친구 섬 구경 · 방명록 (v0.42)
- **친구 맺기**: 섬·광장에서 만난 사람의 캐릭터를 누르면 작은 카드가 떠요 → **친구 신청** / **섬 구경 가기**. 오른쪽 친구 창 '지금 섬에 있는 사람'에서도 신청할 수 있어요. 밖에서 아는 사람은 **6글자 친구 코드**로 신청해요(친구 창 '친구 코드').
- 상대가 **수락**하면 서로 친구. 친구 목록의 **놀러 가기**로 그 친구 섬에 바로 가요(화면이 0.4초 덮였다 걷히는 방 이동). 받은 신청은 빨간 표시 없이 친구 창에만 뜨고, 집에 오면 한 번만 조용히 알려 줘요. 친구를 끊어도 상대에게 알리지 않아요.
- **주인이 없어도 구경**: 섬은 서버에 저장되어 있어서, 주인이 게임을 꺼 두어도 서버에서 꺼내 보여 줘요. 주인이 켜 두면 주인 화면이 보내 주는 지금 모습으로 바뀌고 같이 놀아요.
- **방명록** (v0.43부터 오른쪽 메뉴에 따로, 섬의 **우체통**을 눌러도 열림): 친구 섬에서 한 줄(100자까지) 남기기. 가입한 사람만 쓰고(섬 주인도 자기 방명록에 쓸 수 있어요, v0.44), 유령은 읽기만. 주인은 아무 글이나, 쓴 사람은 자기 글을 지울 수 있어요(두 번 눌러 지우기). 한 섬에 하루 5개까지.
- **유령 손님 받기/막기**: 내 공간 창의 스위치(섬 주인만). 막아 두면 유령은 광장으로 살며시 돌아가요. 유령은 한 섬에 5명까지.
- **다녀온 섬**: 놀러 간 섬 최근 5개를 이 브라우저에 기억해 둬요.
- **초대 링크**는 아직 가입하지 않은 사람용으로 친구 창 아래쪽에 남아 있어요.
- 서버 준비: `docs/supabase-friends.sql`을 Supabase의 SQL Editor에서 한 번 실행. 섬 표는 '내 줄만' 규칙 그대로이고, 섬 번호를 아는 사람에게 그 섬 하나만 보여 주는 창구(함수)로 꺼내요. 친구·방명록 표는 잠가 두고 창구로만 다뤄요. 아직 실행 전이면 게임은 예전처럼 '주인이 켜 둔 동안만 구경'으로 돌아가요.
- 파일: `js/auth.js` 아래쪽(서버 창구), `js/main.js`의 '친구 맺기'·'방명록'·'친구 섬 구경' 부분, `js/party.js`(친구 캐릭터 누르기, 섬 번호 주고받기).

## 조작법
- 켤 때는 언제나 마당 가운데에서 시작해요 (v0.35).
- 걷기: 땅 클릭, 또는 W A S D / 방향키 · 점프: Space · 인사: 1
- 달리기: 이동 키를 빠르게 두 번 누르고 그대로 누르기, 또는 땅을 더블클릭
- 카메라 돌리기: 마우스를 누른 채 끌기 (Q, E 키도 가능) · 가까이/멀리: 마우스 휠
- 꾸미기: 아이템 → 가구 (또는 I 키) → 물건 고르기 → 땅 클릭. 어디든 자유롭게 놓이고, Shift를 누른 채 놓으면 격자 칸에 맞춰짐
- 돌리기: R은 15도씩, Shift+R은 45도씩
- 격자 보기는 가구 창의 "격자 보기" 버튼으로 켜고 끔
- 물건 개수 (v0.40): 물건마다 20개씩 가지고 있어요. 카드 오른쪽 아래 "쓴 개수/가진 개수"(마당+집 안 합계). 다 쓰면 카드가 흐려지고 더 못 놓아요. 치우거나 되돌리면 다시 쓸 수 있어요. 가진 개수는 `js/inventory.js` (나중에 상점에서 늘림)

## 파일 구조
- `index.html`, `style.css`: 화면과 버튼
- `js/palette.js`: 모든 색감 (분위기를 바꿀 때 여기만 고치면 됨)
- `js/catalog.js`: 물건 목록과 모양
- `js/world.js`: 섬과 물건 데이터. 모든 변경은 `apply(action)`을 거쳐서, 나중에 여러 명이 함께 놀 때 이 action을 서버로 주고받으면 됩니다.
- `js/avatar.js`: 아바타
- `js/environment.js`: 하늘·시간·날씨·조명
- `js/storage.js`: 저장/불러오기 (지금은 브라우저 저장, 나중에 서버 저장으로 교체)
- `js/sound.js`: 발소리와 빗소리. 소리 파일 없이 코드로 직접 만든 소리라 저작권 문제가 없습니다.
- `vendor/`: 3D 그리기 도구 three.js (MIT 라이선스)

## 채팅 (지금은 혼자 써보기)
- Enter로 입력, 보내면 머리 위 말풍선 + 왼쪽 아래 기록 창. '기록' 버튼으로 기록 창 보이기/숨기기, '꾸미기'로 잘 어울리는 말풍선 조합 4가지(크림·벚꽃·풀잎·노을) 중 하나 고르기.
- `js/chat.js`의 `LocalTransport`만 서버 연결로 바꾸면 친구에게도 보이게 됩니다.
- 화면 글꼴: Pretendard (길형진, SIL Open Font License 1.1) — `vendor/pretendard`에 함께 담아 어느 컴퓨터에서나 같은 글꼴로 보여요.
- 글씨체 출처 (모두 SIL Open Font License 1.1, 무료·상업적 사용 가능, Google Fonts): 고운돋움(Gowun Dodum, 류양희), 주아(Jua, 배달의민족 우아한형제들), 나눔손글씨 펜(Nanum Pen Script, 네이버).

## 친구와 같은 섬에서 (v0.26, 멀티 첫 버전)
- 오른쪽 메뉴 **친구** → 내 이름 적기 → **초대 링크 복사하기** → 친구에게 보내기. 친구는 링크를 눌러 이름만 적고 들어와요(로그인 없음).
- 서로 걷기·달리기·점프·인사, 채팅 말풍선, 발밑 이름표가 보여요. 위쪽 "지금 N명"이 실제 인원으로 바뀌어요.
- 섬 꾸밈·이름·시간·날씨는 주인 것을 그대로 보여 주고, 손님은 못 바꿔요. 손님 화면은 저장하지 않아요(내 섬이 덮어써지지 않게).
- 주인이 게임을 켜 둔 동안에만 들어올 수 있어요. 섬 모습을 주인 화면이 손님에게 직접 보내 주기 때문이에요(서버 저장은 3단계 로그인 때).
- 서버: Supabase Realtime의 broadcast만 사용 (`js/config.js`에 주소와 공개용 열쇠, `js/net.js` 연결 통로, `js/party.js` 함께 놀기). 데이터베이스는 아직 안 씀.
- 개발 시험: 주소 끝에 `?localtest=1`을 붙이면 서버 없이 같은 브라우저 창끼리 연결돼요.
- `vendor/supabase.js`: supabase-js 2.119.0 (MIT 라이선스)

## 광장 (v0.27)
- 광장 갈 때 이름을 묻지 않아요(v0.32). 이름을 안 적었으면 '나그네'로 보여요.
- 누구나 처음엔 자기 섬에서 시작해요. 위쪽 **광장 가기** 버튼으로 광장에, **우리 집 가기**로 내 섬에 돌아와요 (화면이 0.4초 부드럽게 덮였다가 걷혀요).
- 광장은 작은 마을 광장: 가운데 분수대, 벤치 4개, 가로등 4개, 큰 나무 한 그루, 가장자리로 뻗은 디딤돌 길 3갈래(나중에 다른 장소 입구 자리). 모습은 `js/world.js`의 `PLAZA_ITEMS`.
- 광장은 주인이 없어서 누가 켜 두지 않아도 열려 있고, 한국 실제 시간·맑은 날씨로 보여요. 꾸미기·저장은 안 돼요.
- 초대 링크로 들어온 친구는 바로 그 섬으로 가요.

## 우리 집 (v0.31, 화면 전환 없이 그 자리에서 열리기)
- 섬마다 둥근 지붕 오두막이 한 채 있어요 (`js/catalog.js`의 `cottage`, 크기 `HOUSE_W/D/H` = 11 × 8.5 × 2.8, 자리는 `js/world.js`의 `HOUSE_SPOT`). 꾸미기에서 옮기기·돌리기는 되고, 치우기는 안 돼요.
- 문 앞으로 걸어가거나 집을 클릭하면, 화면이 바뀌지 않고 그 자리에서 지붕이 스르륵 사라지고 카메라 쪽 벽이 낮아지면서 집 안 방이 보여요. 둘레의 마당과 친구들도 그대로 보여요.
- 원리: 바깥 집과 집 안 방은 같은 크기. 집 안에 있는 동안엔 '집 가운데 = (0,0)'인 집 기준 자리를 쓰고, 마당 전체(`world.frame`)를 그만큼 돌려 놓아요 (`World.enterHouse / exitHouse`).
- 앞쪽 가운데 문으로 걸어 나가면 지붕이 다시 덮이고 마당으로 돌아와요. 따로 나가는 버튼 없이, 집 안에서 마당을 누르면 문으로 걸어 나가 그 자리까지 이어서 걸어가요 (v0.35).
- 집 안에서 화면을 돌려도 벽이 오르내리지 않아요. 카메라 쪽 벽은 발목보다 낮은 얇은 테두리(약 15cm)만 남아요 (v0.38). 지붕은 사라지는 모션 없이 들어가자마자 안 보이고, 들어가고 나오는 순간 화면이 튀지 않아요. 창문은 실제로 뚫려 있어서 바깥 풍경이 보여요 (v0.40).
- 집 안도 같은 가구 창으로 꾸미고, 마당과 따로 저장돼요 (저장 5판: `house.items`). 예전 저장은 집 자리와 겹치는 물건만 옆으로 비켜 주고 그대로 이어져요.
- 집 안(지붕 자리)에는 비·눈이 안 들어오고, 빗소리·풍경 소리는 작게 들려요.
- 친구도 같이 들어갈 수 있어요. 내가 집 안이면 마당의 친구도 보이고, 내가 마당이면 집 안 친구는 지붕에 가려 안 보여요.
- 방 가구 5가지: 둥근 러그, 나무 의자, 작은 침대, 책장, 화분.

## 모션
- 채팅줄 **모션** 칸에서 인사. 새 모션은 `js/main.js`의 `MOTIONS` 목록에 한 줄 더하면 버튼이 생겨요.
- 채팅에 "안녕"이 들어가면 저절로 손을 흔들어요 (친구 화면에도).

## 주인 / 손님 규칙
섬의 시간·날씨·꾸미기는 주인(방장)이 정하고, 손님은 바꿀 수 없습니다. `js/main.js`의 `setRole('guest')`를 부르면 손님 화면이 됩니다(방문 기능 단계에서 연결).

## 버전
- v0.33부터: 켤 때·화면으로 돌아올 때 서버의 최신 버전 번호를 새로 받아 보고, 더 새것이면 한 번 저절로 새로 고쳐요 (휴대폰이 예전 화면을 기억해 두는 문제 때문).
고칠 때마다 `index.html`과 `js/*.js`의 `?v=` 숫자를 함께 올립니다. 브라우저가 예전 파일을 기억해 두지 않고 새 파일을 받게 하기 위해서입니다. 화면 오른쪽 아래에 지금 버전이 보입니다.

## 되돌리기
- `Ctrl`+`Z` 되돌리기, `Ctrl`+`Shift`+`Z`(또는 `Ctrl`+`Y`) 다시 하기. 맥은 `Cmd`.
- 놓기·옮기기·돌리기·치우기·처음 모습으로, 모두 되돌릴 수 있어요 (창을 새로 고치기 전까지, 최근 100번).

## 아이콘
- 아이콘은 이모지 대신 `js/icons.js`에 직접 그린 선 아이콘 한 벌을 써요 (24칸, 선 굵기 1.8, 둥근 끝). 색은 글자 색을 따라가요.
- 아이템 카드 그림은 `js/thumbs.js`가 게임 속 3D 물건을 그대로 찍어서 만들어요. 물건 모양을 고치면 카드도 같이 바뀌어요.
